# Relics of the old project

**What is here is a relic, not a truth about this project.** It comes from the old version of the game and is kept only so the user does not have to send it again. Nothing here is a rule, a format or a number of the current game.

What is true about the current game is in `AGENTS.md` and in `src/data.js` (each number has its reason beside it). When a relic and those disagree, the relic loses. Names also differ on purpose: for example, the old `Armor` is the current **health**, and the old `Halo` is the shield, which the current game does not have yet.

Use a relic to understand **what the user had in mind**, never to copy its structure or its values. If something in a relic is wanted again, it must be decided with the user and then written in `AGENTS.md`.
